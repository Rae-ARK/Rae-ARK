## <a id="about"></a>📖 என்னைப் பற்றி

- ✍️ பொழுதுபோக்கு வெப் நாவலாசிரியன் — ஃபான்டசி மற்றும் சயின்ஸ் ஃபான்டசி, பெரும்பாலும் தங்களை மீண்டும் கட்டமைக்கும் மனிதர்களைப் பற்றியது.
- 📚 மறுபிறவி, ஐசேகாய், சமகால நாடகம் ஆகியவற்றை உள்ளடக்கிய மூன்று தொடர் படைப்புகள்.
- 🖋️ எனது சொந்த இம்ப்ரிண்ட் `Unofficially`, **Horizon ARK Studio** என்பதன் கீழ் வெளியிடுகிறேன்.
- 💻 தொழில்முறை புரோகிராமர் அல்ல — எனக்கு ஒரு குறிப்பிட்ட விஷயம் தேவைப்படும்போது (எனது ஆசிரியர் தளம் போல) சிறிய தனிப்பட்ட கருவிகளை உருவாக்குகிறேன்.
- 🎯 இலக்கு: நான் தொடங்கியதை முடிப்பது, வேண்டுமென்றே குறுகியதாக வடிவமைக்கப்பட்ட திட்டங்களாக இருந்தாலும் சரி.

### 🌐 ஆசிரியர் தளம் + ஆண்ட்ராய்டு ஆப்
Vue 3 + TypeScript-இல் உருவாக்கப்பட்ட தளம் (முகப்பு / படைப்புகள் / கடை / பதிவேடு / பற்றி / கருத்து / தனியுரிமை / விதிமுறைகள்), உங்கள் சிஸ்டத்தைப் பின்பற்றும் லைட்/டார்க் தீம், ஆஃப்லைன் ஆதரவு, மற்றும் Capacitor மூலம் பொதிந்த native ஆண்ட்ராய்டு ஆப் — ஹார்ட்வேர் பேக் பட்டன், native நிலைப்பட்டை, எட்ஜ்-டு-எட்ஜ் திரைகளுக்கான safe-area அமைப்பு. ஒவ்வொரு push-இலும் debug APK CI வழியாக தானாகவே உருவாக்கப்படுகிறது.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **அடுத்து:** இந்தத் தளத்தை Vue 3-இலிருந்து **[ARKlight](https://github.com/Rae-ARK/ARKlight)** என்பதற்கு மாற்றுகிறேன் — இணையாக நான் உருவாக்கும் Python-முதல் நிலையான தள தொகுப்பி, பக்கங்களை Python செயல்பாடுகளாக எழுதுங்கள், அது எளிய HTML/CSS/JS ஆக தொகுக்கப்படும்.
