## <a id="about"></a>📖 Sobre mim

- ✍️ Autor amador de web novels — fantasia e fantasia científica, em sua maioria sobre pessoas que se reconstroem.
- 📚 Três obras em andamento, abrangendo reencarnação, isekai e drama contemporâneo.
- 🖋️ Publico sob meu próprio selo, `Unofficially`, **Horizon ARK Studio**.
- 💻 Não sou programador de profissão — faço pequenas ferramentas pessoais (como meu site de autor) quando preciso que algo específico exista.
- 🎯 Meta: terminar o que começo, até os projetos feitos para serem curtos de propósito.

### 🌐 Site do autor + app Android
Um site em Vue 3 + TypeScript (Início / Obras / Loja / Diário / Sobre / Feedback / Privacidade / Termos) com tema claro/escuro que acompanha o sistema, suporte offline e um app Android nativo empacotado com Capacitor — botão físico de voltar, barra de status nativa e layout que respeita as áreas seguras em telas de ponta a ponta. O APK de depuração é gerado automaticamente por CI a cada push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **A seguir:** migrar este site do Vue 3 para o **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — um compilador de sites estáticos centrado em Python que estou desenvolvendo em paralelo: as páginas são escritas como funções Python e compiladas para HTML/CSS/JS puro.
