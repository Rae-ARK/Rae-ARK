## <a id="about"></a>📖 എന്നെക്കുറിച്ച്

- ✍️ ഹോബിയായി വെബ് നോവൽ എഴുതുന്നയാൾ — ഫാന്റസിയും സയൻസ് ഫാന്റസിയും, കൂടുതലും സ്വയം പുനർനിർമ്മിക്കുന്ന ആളുകളെക്കുറിച്ച്.
- 📚 മൂന്ന് തുടരുന്ന രചനകൾ — പുനർജന്മം, ഐസെകായ്, സമകാലിക ഡ്രാമ എന്നിവ ഉൾക്കൊള്ളുന്നു.
- 🖋️ എന്റെ സ്വന്തം ഇംപ്രിന്റായ `Unofficially`, **Horizon ARK Studio** എന്നതിന് കീഴിൽ പ്രസിദ്ധീകരിക്കുന്നു.
- 💻 തൊഴിൽപരമായി കോഡർ അല്ല — എനിക്ക് പ്രത്യേകമായി എന്തെങ്കിലും വേണമെങ്കിൽ (എന്റെ രചയിതാവിന്റെ വെബ്സൈറ്റ് പോലെ) ചെറിയ വ്യക്തിഗത ടൂളുകൾ ഞാൻ ഉണ്ടാക്കും.
- 🎯 ലക്ഷ്യം: തുടങ്ങിയത് പൂർത്തിയാക്കുക, മനഃപൂർവ്വം ചെറുതായി രൂപകൽപ്പന ചെയ്ത പ്രോജക്ടുകൾ ആണെങ്കിൽ പോലും.

### 🌐 രചയിതാവിന്റെ സൈറ്റ് + ആൻഡ്രോയിഡ് ആപ്പ്
Vue 3 + TypeScript ഉപയോഗിച്ചുള്ള ഒരു സൈറ്റ് (ഹോം / രചനകൾ / സ്റ്റോർ / ജേണൽ / എന്നെക്കുറിച്ച് / ഫീഡ്ബാക്ക് / സ്വകാര്യത / നിബന്ധനകൾ) നിങ്ങളുടെ സിസ്റ്റത്തെ പിന്തുടരുന്ന ലൈറ്റ്/ഡാർക്ക് തീമോടും ഓഫ്‌ലൈൻ പിന്തുണയോടും, Capacitor വഴി പാക്ക് ചെയ്ത ഒരു നേറ്റീവ് ആൻഡ്രോയിഡ് ആപ്പോടും കൂടി — ഹാർഡ്‌വെയർ ബാക്ക് ബട്ടൺ, നേറ്റീവ് സ്റ്റാറ്റസ് ബാർ, എഡ്ജ്-ടു-എഡ്ജ് സ്ക്രീനുകൾക്കായുള്ള സേഫ്-ഏരിയ ലേഔട്ട്. ഓരോ പുഷിലും CI വഴി ഡീബഗ് APK സ്വയമേവ നിർമ്മിക്കപ്പെടുന്നു.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **അടുത്തത്:** ഈ സൈറ്റ് Vue 3-ൽ നിന്ന് **[ARKlight](https://github.com/Rae-ARK/ARKlight)** എന്നതിലേക്ക് മാറ്റുന്നു — ഞാൻ സമാന്തരമായി നിർമ്മിക്കുന്ന ഒരു Python-ഫസ്റ്റ് സ്റ്റാറ്റിക് സൈറ്റ് കമ്പൈലർ, പേജുകൾ Python ഫംഗ്ഷനുകളായി എഴുതുക, അത് ലളിതമായ HTML/CSS/JS ആയി കമ്പൈൽ ചെയ്യും.
