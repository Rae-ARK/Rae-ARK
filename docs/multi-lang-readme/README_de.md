Ich bin kein Entwickler – ich bin ein Web-Romanautor, der zufällig die Werkzeuge, die er braucht, selbst baut. Dieses Profil und alles darunter existiert, weil ich es wollte und herausgefunden habe, wie es geht – nicht, weil ich das beruflich mache.

---

## <a id="about"></a>📖 Über mich

- ✍️ Hobby-Webromanautor – Fantasy und Science-Fantasy, meist über Menschen, die sich neu erfinden.
- 📚 Drei laufende Werke zwischen Reinkarnation, Isekai und zeitgenössischem Drama.
- 🖋️ Veröffentlichung unter meinem eigenen Imprint `Unofficially`, **Horizon ARK Studio**.
- 💻 Kein Programmierer von Beruf – ich baue kleine persönliche Tools (etwa meine Autorenseite), wenn etwas Bestimmtes existieren soll.
- 🎯 Ziel: Zu Ende bringen, was ich anfange – auch die Projekte, die absichtlich kurz angelegt sind.

### 🌐 Autorenseite + Android-App
Eine Website mit Vue 3 + TypeScript (Start / Werke / Shop / Journal / Über / Feedback / Datenschutz / Bedingungen) mit hellem/dunklem Design, das dem System folgt, Offline-Unterstützung und einer nativen Android-App via Capacitor – mit Hardware-Zurück-Taste, nativer Statusleiste und Safe-Area-bewusstem Layout für randlose Displays. Der Debug-APK wird bei jedem Push automatisch per CI gebaut.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Als Nächstes:** Die Seite zieht von Vue 3 auf **[ARKlight](https://github.com/Rae-ARK/ARKlight)** um – einen Python-zentrierten Static-Site-Compiler, den ich parallel entwickle: Seiten werden als Python-Funktionen geschrieben und zu reinem HTML/CSS/JS kompiliert.
