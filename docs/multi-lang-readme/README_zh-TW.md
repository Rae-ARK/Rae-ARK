我不是開發者——我是一名網路小說作者，碰巧會自己動手做我需要的工具。這份個人主頁以及下面的一切，都是因為我想要它們存在、並且摸索出了方法，而不是因為我以此為業。

## <a id="about"></a>📖 關於我

- ✍️ 業餘網路小說作者——奇幻與科幻奇幻，故事大多關於人們重建自我。
- 📚 三部連載作品，涵蓋轉生、異世界與現代劇情。
- 🖋️ 以我自己的品牌 `Unofficially`、**Horizon ARK Studio** 發布作品。
- 💻 並非職業程式設計師——當我需要某樣特定的東西時，就會自己做一些小工具（比如我的作者網站）。
- 🎯 目標：把開始的事做完，即使是那些本來就設計得很短的專案。

### 🌐 作者網站 + Android 應用程式
基於 Vue 3 + TypeScript 的網站（首頁 / 作品 / 商店 / 日誌 / 關於 / 意見回饋 / 隱私權 / 條款），支援跟隨系統的明暗主題、離線存取，並透過 Capacitor 封裝為原生 Android 應用程式——支援硬體返回鍵、原生狀態列，以及適配全螢幕的安全區域版面配置。每次 push 都會透過 CI 自動建置除錯版 APK。

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **接下來：** 把該網站從 Vue 3 遷移到 **[ARKlight](https://github.com/Rae-ARK/ARKlight)**——我正在同步開發的 Python 優先靜態網站編譯器，用 Python 函式編寫頁面，並編譯為純 HTML/CSS/JS。

</details>
