## <a id="about"></a>📖 เกี่ยวกับฉัน

- ✍️ นักเขียนเว็บนิยายสมัครเล่น — แฟนตาซีและไซไฟแฟนตาซี ส่วนใหญ่เป็นเรื่องของผู้คนที่กำลังสร้างตัวเองขึ้นใหม่
- 📚 ผลงานที่กำลังลงต่อเนื่อง 3 เรื่อง ครอบคลุมการกลับชาติมาเกิด ต่างโลก และดราม่าร่วมสมัย
- 🖋️ ตีพิมพ์ภายใต้สำนักพิมพ์ของตัวเอง `Unofficially`, **Horizon ARK Studio**
- 💻 ไม่ได้เป็นโปรแกรมเมอร์อาชีพ — ฉันทำเครื่องมือส่วนตัวเล็ก ๆ (เช่น เว็บไซต์นักเขียนของฉัน) เมื่อต้องการให้บางสิ่งที่เฉพาะเจาะจงเกิดขึ้น
- 🎯 เป้าหมาย: ทำสิ่งที่เริ่มไว้ให้จบ แม้แต่โปรเจกต์ที่ตั้งใจออกแบบให้สั้น

### 🌐 เว็บไซต์นักเขียน + แอป Android
เว็บไซต์ที่สร้างด้วย Vue 3 + TypeScript (หน้าแรก / ผลงาน / ร้านค้า / บันทึก / เกี่ยวกับ / ข้อเสนอแนะ / ความเป็นส่วนตัว / ข้อกำหนด) พร้อมธีมสว่าง/มืดที่ตามระบบ รองรับออฟไลน์ และแอป Android เนทีฟที่ห่อด้วย Capacitor — รองรับปุ่มย้อนกลับของเครื่อง แถบสถานะเนทีฟ และเลย์เอาต์ที่คำนึงถึง safe area สำหรับหน้าจอเต็มขอบ ไฟล์ APK สำหรับดีบักถูกสร้างอัตโนมัติผ่าน CI ทุกครั้งที่ push

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **ขั้นต่อไป:** ย้ายเว็บไซต์นี้จาก Vue 3 ไปใช้ **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — คอมไพเลอร์เว็บไซต์สแตติกแบบ Python-first ที่ฉันกำลังพัฒนาควบคู่กัน เขียนหน้าเว็บเป็นฟังก์ชัน Python แล้วมันจะคอมไพล์เป็น HTML/CSS/JS ธรรมดา
