## <a id="about"></a>📖 O mnie

- ✍️ Hobbystyczny autor webnowel — fantasy i science fantasy, głównie o ludziach, którzy odbudowują samych siebie.
- 📚 Trzy trwające utwory, obejmujące reinkarnację, isekai i współczesny dramat.
- 🖋️ Publikuję pod własnym imprintem `Unofficially`, **Horizon ARK Studio**.
- 💻 Nie jestem programistą z zawodu — robię małe osobiste narzędzia (jak moja strona autorska), gdy potrzebuję, żeby coś konkretnego istniało.
- 🎯 Cel: kończyć to, co zaczynam, nawet projekty celowo zaprojektowane jako krótkie.

### 🌐 Strona autora + aplikacja na Androida
Strona w Vue 3 + TypeScript (Strona główna / Utwory / Sklep / Dziennik / O autorze / Opinie / Prywatność / Regulamin) z jasnym i ciemnym motywem zgodnym z systemem, obsługą offline oraz natywną aplikacją na Androida opakowaną w Capacitor — sprzętowy przycisk wstecz, natywny pasek stanu, układ uwzględniający bezpieczne strefy dla ekranów od krawędzi do krawędzi. Debugowy plik APK jest budowany automatycznie przez CI przy każdym pushu.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Dalej:** przenoszę tę stronę z Vue 3 na **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — kompilator statycznych stron zorientowany na Pythona, który rozwijam równolegle: strony pisze się jako funkcje Pythona, a on kompiluje je do zwykłego HTML/CSS/JS.
