## <a id="about"></a>📖 Về tôi

- ✍️ Tác giả tiểu thuyết mạng nghiệp dư — giả tưởng và khoa học giả tưởng, phần lớn về những con người tự xây dựng lại bản thân.
- 📚 Ba tác phẩm đang ra, trải dài từ chuyển sinh, isekai đến chính kịch đương đại.
- 🖋️ Xuất bản dưới thương hiệu riêng `Unofficially`, **Horizon ARK Studio**.
- 💻 Không làm nghề lập trình — tôi tự làm những công cụ nhỏ (như trang tác giả của mình) khi cần một thứ cụ thể.
- 🎯 Mục tiêu: hoàn thành những gì mình đã bắt đầu, kể cả những dự án cố tình thiết kế ngắn.

### 🌐 Trang tác giả + Ứng dụng Android
Một trang web dùng Vue 3 + TypeScript (Trang chủ / Tác phẩm / Cửa hàng / Nhật ký / Giới thiệu / Phản hồi / Quyền riêng tư / Điều khoản) với giao diện sáng/tối theo hệ thống, hỗ trợ ngoại tuyến và một ứng dụng Android gốc đóng gói bằng Capacitor — nút Back vật lý, thanh trạng thái gốc, bố cục nhận biết vùng an toàn cho màn hình tràn viền. APK gỡ lỗi được CI tự động build sau mỗi lần push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Tiếp theo:** chuyển trang này từ Vue 3 sang **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — một trình biên dịch trang tĩnh ưu tiên Python mà tôi đang phát triển song song: viết trang như các hàm Python và nó biên dịch thành HTML/CSS/JS thuần.
