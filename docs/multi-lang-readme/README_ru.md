### 🌐 Сайт автора + приложение для Android
Сайт на Vue 3 + TypeScript (Главная / Произведения / Магазин / Журнал / Об авторе / Обратная связь / Конфиденциальность / Условия) со светлой и тёмной темами, которые следуют системным настройкам, офлайн-режимом и нативным приложением для Android на базе Capacitor — аппаратная кнопка «Назад», нативная строка состояния, макет с учётом безопасных зон для экранов во весь дисплей. Отладочный APK автоматически собирается через CI при каждом push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Дальше:** перенос этого сайта с Vue 3 на **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — статический компилятор сайтов на Python, который я разрабатываю параллельно: страницы пишутся как функции Python и компилируются в обычные HTML/CSS/JS.
