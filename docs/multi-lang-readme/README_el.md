## <a id="about"></a>📖 Σχετικά με εμένα

- ✍️ Ερασιτέχνης συγγραφέας web novels — φαντασία και επιστημονική φαντασία, κυρίως για ανθρώπους που ξαναχτίζουν τον εαυτό τους.
- 📚 Τρία συνεχιζόμενα έργα, που καλύπτουν μετενσάρκωση, isekai και σύγχρονο δράμα.
- 🖋️ Εκδίδω με τη δική μου σφραγίδα, `Unofficially`, **Horizon ARK Studio**.
- 💻 Δεν είμαι προγραμματιστής στο επάγγελμα — φτιάχνω μικρά προσωπικά εργαλεία (όπως τον ιστότοπό μου ως συγγραφέα) όταν χρειάζομαι να υπάρξει κάτι συγκεκριμένο.
- 🎯 Στόχος: να ολοκληρώνω ό,τι ξεκινώ, ακόμη και τα έργα που σχεδιάστηκαν σκόπιμα να είναι σύντομα.

### 🌐 Ιστότοπος συγγραφέα + εφαρμογή Android
Ένας ιστότοπος σε Vue 3 + TypeScript (Αρχική / Έργα / Κατάστημα / Ημερολόγιο / Σχετικά / Σχόλια / Απόρρητο / Όροι) με φωτεινό/σκούρο θέμα που ακολουθεί το σύστημα, υποστήριξη εκτός σύνδεσης και μια εγγενή εφαρμογή Android τυλιγμένη με Capacitor — φυσικό κουμπί πίσω, εγγενής γραμμή κατάστασης, διάταξη που λαμβάνει υπόψη τις ασφαλείς ζώνες για οθόνες από άκρη σε άκρη. Το debug APK δημιουργείται αυτόματα μέσω CI σε κάθε push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Επόμενο βήμα:** μεταφορά αυτού του ιστότοπου από το Vue 3 στο **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — έναν μεταγλωττιστή στατικών ιστότοπων με προτεραιότητα στην Python που αναπτύσσω παράλληλα: οι σελίδες γράφονται ως συναρτήσεις Python και μεταγλωττίζονται σε απλό HTML/CSS/JS.
