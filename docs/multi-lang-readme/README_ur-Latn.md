## <a id="about"></a>📖 Mere Baare Mein

- ✍️ Shauqiya web novelist — fantasy aur science fantasy, zyadatar un logon ke baare mein jo khud ko dobara banate hain.
- 📚 Teen jaari kaam, jo reincarnation, isekai, aur contemporary drama tak phaile hue hain.
- 🖋️ Apne khud ke imprint `Unofficially`, **Horizon ARK Studio** ke tehat publish karta hoon.
- 💻 Peshe ke hisaab se coder nahi hoon — jab mujhe kisi khaas cheez ki zaroorat hoti hai (jaise mera author site) to chhote personal tools bana leta hoon.
- 🎯 Maqsad: jo shuru karta hoon usay khatam karna, chahe projects jaan-boojh kar chhote banaye gaye hon.

### 🌐 Author Site + Android App
Vue 3 + TypeScript se bani ek site (Home / Kaam / Store / Journal / Baare Mein / Feedback / Privacy / Terms) jisme light/dark theme aapke system ko follow karti hai, offline support, aur Capacitor ke zariye wrap ki gayi ek native Android app — hardware back button, native status bar, edge-to-edge screens ke liye safe-area-aware layout. Debug APK har push par CI ke zariye khud-ba-khud build hota hai.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Aage kya:** is site ko Vue 3 se hata kar **[ARKlight](https://github.com/Rae-ARK/ARKlight)** par le jana — ek Python-first static site compiler jo main parallel mein bana raha hoon, pages ko Python functions ki tarah likhein aur yeh plain HTML/CSS/JS mein compile ho jata hai.
