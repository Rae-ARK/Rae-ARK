- 🎯 الهدف: إنهاء ما أبدأه، حتى المشاريع التي صُمّمت لتكون قصيرة عمدًا.

### 🌐 موقع الكاتب + تطبيق أندرويد
موقع مبني بـ Vue 3 + TypeScript (الرئيسية / الأعمال / المتجر / اليوميات / نبذة / الملاحظات / الخصوصية / الشروط) مع سمة فاتحة/داكنة تتبع النظام ودعم للعمل دون اتصال، وتطبيق أندرويد أصلي مغلّف عبر Capacitor — زر الرجوع الفعلي وشريط الحالة الأصلي وتخطيط يراعي المناطق الآمنة للشاشات الممتدة حتى الحواف. يُبنى ملف APK للتصحيح تلقائيًا عبر CI مع كل عملية push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **الخطوة التالية:** نقل هذا الموقع من Vue 3 إلى **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — مترجم مواقع ثابتة يعتمد Python أولًا أطوّره بالتوازي، تُكتب الصفحات كدوال Python ثم تُترجم إلى HTML/CSS/JS عادية.
