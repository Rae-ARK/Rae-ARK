من توسعه‌دهنده نیستم — نویسنده‌ی وب‌نوولم و اتفاقاً ابزارهای موردنیازم را خودم می‌سازم. این پروفایل و همه‌چیز در ادامه وجود دارد چون می‌خواستم وجود داشته باشد و راهش را پیدا کردم، نه به این خاطر که این کار شغل حرفه‌ای من باشد.

## <a id="about"></a>📖 درباره‌ی من

- ✍️ نویسنده‌ی آماتور وب‌نوول — فانتزی و فانتزی علمی، بیشتر درباره‌ی آدم‌هایی که خودشان را از نو می‌سازند.
- 📚 سه اثر در حال انتشار، شامل بازتولد، ایسکای و درام معاصر.
- 🖋️ با نشان انتشاراتی خودم، `Unofficially`، یعنی **Horizon ARK Studio** منتشر می‌کنم.
- 💻 برنامه‌نویس حرفه‌ای نیستم — وقتی به چیز مشخصی نیاز دارم، ابزارهای شخصی کوچک (مثل سایت نویسنده‌ام) می‌سازم.
- 🎯 هدف: تمام کردن آنچه شروع می‌کنم، حتی پروژه‌هایی که عمداً کوتاه طراحی شده‌اند.

### 🌐 سایت نویسنده + اپلیکیشن اندروید
سایتی با Vue 3 + TypeScript (خانه / آثار / فروشگاه / یادداشت‌ها / درباره / بازخورد / حریم خصوصی / شرایط) با پوسته‌ی روشن/تیره که از سیستم پیروی می‌کند، پشتیبانی آفلاین و یک اپلیکیشن بومی اندروید که با Capacitor بسته‌بندی شده — دکمه‌ی فیزیکی بازگشت، نوار وضعیت بومی و چیدمانی سازگار با ناحیه‌ی امن برای نمایشگرهای لبه‌به‌لبه. فایل APK اشکال‌زدایی در هر push به‌طور خودکار با CI ساخته می‌شود.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **قدم بعدی:** انتقال این سایت از Vue 3 به **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — کامپایلر سایت‌های ایستا با رویکرد Python که به‌موازات در حال ساختنش هستم؛ صفحات را به‌صورت توابع Python می‌نویسید و به HTML/CSS/JS ساده کامپایل می‌شود.

</details>
