<details>
<summary>Tampilkan detail</summary>

### 🌐 Situs Penulis + Aplikasi Android
Situs berbasis Vue 3 + TypeScript (Beranda / Karya / Toko / Jurnal / Tentang / Masukan / Privasi / Ketentuan) dengan tema terang/gelap yang mengikuti sistem, dukungan offline, dan aplikasi Android native yang dibungkus dengan Capacitor — tombol kembali perangkat keras, status bar native, dan tata letak yang memperhatikan safe area untuk layar edge-to-edge. APK debug dibangun otomatis lewat CI pada setiap push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Berikutnya:** memindahkan situs ini dari Vue 3 ke **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — kompiler situs statis berbasis Python yang saya kembangkan secara paralel: halaman ditulis sebagai fungsi Python dan dikompilasi menjadi HTML/CSS/JS biasa.
