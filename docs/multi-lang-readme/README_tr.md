## <a id="about"></a>📖 Hakkımda

- ✍️ Hobi olarak web romanı yazıyorum — fantezi ve bilim fantezi, çoğunlukla kendilerini yeniden inşa eden insanlar hakkında.
- 📚 Reenkarnasyon, isekai ve çağdaş dramayı kapsayan üç devam eden eser.
- 🖋️ Kendi yayın markam `Unofficially` altında, **Horizon ARK Studio** ile yayımlıyorum.
- 💻 Mesleğim kodlama değil — belirli bir şeyin var olmasına ihtiyaç duyduğumda (yazar sitem gibi) küçük kişisel araçlar yaparım.
- 🎯 Hedef: başladığım işi bitirmek; kasıtlı olarak kısa tasarlanmış projeler dahil.

### 🌐 Yazar Sitesi + Android Uygulaması
Vue 3 + TypeScript ile yazılmış bir site (Ana Sayfa / Eserler / Mağaza / Günlük / Hakkında / Geri Bildirim / Gizlilik / Koşullar); sistemi takip eden açık/koyu tema, çevrimdışı destek ve Capacitor ile sarmalanmış yerel bir Android uygulaması — donanım geri tuşu, yerel durum çubuğu, kenardan kenara ekranlar için güvenli alan duyarlı düzen. Hata ayıklama APK'sı her push'ta CI ile otomatik derlenir.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Sırada:** bu siteyi Vue 3'ten **[ARKlight](https://github.com/Rae-ARK/ARKlight)**'a taşımak — paralel olarak geliştirdiğim, Python öncelikli bir statik site derleyicisi; sayfalar Python fonksiyonları olarak yazılır ve düz HTML/CSS/JS'ye derlenir.
