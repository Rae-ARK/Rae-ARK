### 🌐 Авторски сайт + приложение за Android
Сайт с Vue 3 + TypeScript (Начало / Произведения / Магазин / Дневник / За автора / Обратна връзка / Поверителност / Условия) със светла и тъмна тема, следваща системата, офлайн поддръжка и нативно Android приложение, опаковано с Capacitor — хардуерен бутон „назад“, нативна лента за състоянието, оформление, съобразено с безопасните зони за екрани от край до край. Debug APK се компилира автоматично чрез CI при всеки push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Следва:** преместване на този сайт от Vue 3 към **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — компилатор за статични сайтове с приоритет на Python, който разработвам паралелно: страниците се пишат като функции на Python и се компилират до обикновен HTML/CSS/JS.
