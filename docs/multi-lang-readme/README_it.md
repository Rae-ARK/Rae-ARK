## <a id="about"></a>📖 Chi sono

- ✍️ Autore amatoriale di web novel — fantasy e science fantasy, soprattutto su persone che ricostruiscono sé stesse.
- 📚 Tre opere in corso, tra reincarnazione, isekai e dramma contemporaneo.
- 🖋️ Pubblico con il mio marchio editoriale, `Unofficially`, **Horizon ARK Studio**.
- 💻 Non sono un programmatore di mestiere: creo piccoli strumenti personali (come il mio sito d'autore) quando mi serve che esista qualcosa di specifico.
- 🎯 Obiettivo: finire ciò che inizio, anche i progetti pensati per essere brevi di proposito.

### 🌐 Sito d'autore + app Android
Un sito in Vue 3 + TypeScript (Home / Opere / Negozio / Diario / Chi sono / Feedback / Privacy / Termini) con tema chiaro/scuro che segue il sistema, supporto offline e un'app Android nativa incapsulata con Capacitor: pulsante indietro hardware, barra di stato nativa, layout attento alle safe area per gli schermi edge-to-edge. L'APK di debug viene compilato automaticamente dalla CI a ogni push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Prossimo passo:** migrare questo sito da Vue 3 a **[ARKlight](https://github.com/Rae-ARK/ARKlight)**, un compilatore di siti statici Python-first che sto sviluppando in parallelo: le pagine si scrivono come funzioni Python e vengono compilate in semplice HTML/CSS/JS.
