### 🌐 Сайт автора + застосунок для Android
Сайт на Vue 3 + TypeScript (Головна / Твори / Магазин / Журнал / Про автора / Відгуки / Конфіденційність / Умови) зі світлою й темною темами, що слідують системним налаштуванням, офлайн-режимом і нативним застосунком для Android на основі Capacitor — апаратна кнопка «Назад», нативний рядок стану, макет із урахуванням безпечних зон для екранів на всю поверхню. Налагоджувальний APK автоматично збирається через CI після кожного push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Далі:** перенесення цього сайту з Vue 3 на **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — статичний компілятор сайтів на Python, який я розробляю паралельно: сторінки пишуться як функції Python і компілюються у звичайні HTML/CSS/JS.
