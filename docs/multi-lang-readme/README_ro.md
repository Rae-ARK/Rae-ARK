## <a id="about"></a>📖 Despre mine

- ✍️ Autor amator de web novel-uri — fantasy și science fantasy, mai ales despre oameni care se reconstruiesc.
- 📚 Trei lucrări în curs, între reîncarnare, isekai și dramă contemporană.
- 🖋️ Public sub propria mea marcă editorială, `Unofficially`, **Horizon ARK Studio**.
- 💻 Nu sunt programator de meserie — fac mici unelte personale (precum site-ul meu de autor) când am nevoie ca ceva anume să existe.
- 🎯 Obiectiv: să termin ce încep, chiar și proiectele concepute intenționat să fie scurte.

### 🌐 Site-ul autorului + aplicație Android
Un site în Vue 3 + TypeScript (Acasă / Lucrări / Magazin / Jurnal / Despre / Feedback / Confidențialitate / Termeni) cu temă luminoasă/întunecată care urmează sistemul, suport offline și o aplicație Android nativă împachetată cu Capacitor — buton fizic înapoi, bară de stare nativă, aspect care ține cont de zonele sigure pentru ecrane de la margine la margine. APK-ul de depanare se compilează automat prin CI la fiecare push.

`Vue 3` `TypeScript` `Vite` `Capacitor` `Android` `Cloudflare Workers`

[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/Rae-ARK/ARKfolio)

> 🔄 **Urmează:** mutarea acestui site de pe Vue 3 pe **[ARKlight](https://github.com/Rae-ARK/ARKlight)** — un compilator de site-uri statice orientat spre Python, pe care îl dezvolt în paralel: paginile se scriu ca funcții Python și se compilează în HTML/CSS/JS simplu.

</details>
